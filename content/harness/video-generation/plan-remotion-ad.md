# Plan Remotion Ad

Use the release-context findings and product-flow handoff as the creative brief for a Remotion advertisement.

Create a concrete Remotion composition plan for a new-feature release video.

Use safe defaults unless the user provided specifics:

- Format: 16:9 landscape
- Duration: 30-45 seconds
- Tone: polished product release advertisement
- Visual style: clean SaaS product demo with clear feature callouts
- Primary content: repository-derived new features and local app flow

Expected handoff:

- Composition name
- Scene order with durations
- HTML-to-Remotion mapping notes
- Animation direction
- Voiceover or caption copy when useful
- Asset assumptions
- Any blocker that would prevent implementation or rendering

Do not render the video in this step. Do not claim files were created unless the runtime confirms them.
