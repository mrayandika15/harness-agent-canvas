# Read Release Context

Use the Harness Agent Canvas repository as the source material for the video narrative.

Read either the local repository or the GitHub repository at https://github.com/mrayandika15/harness-agent-canvas when available in runtime context.

Focus only on commit history, repository-visible changes, and product-relevant context. Identify what is new, notable, user-facing, or suitable for a short release advertisement.

Return a concise handoff containing:

- Recent feature names or themes
- Commit references or short commit identifiers when available
- One-sentence value proposition for each feature
- Any uncertainty where commit messages or source context are unclear

Do not implement code, edit files, render video, run tests, execute the workflow, or inspect unrelated websites.
